# 桌面课表工具（Windows · Python 3.13）

一个悬浮在屏幕右侧、始终置顶的桌面课表：开机自启后按当前日期与单双周自动展示今日课程，
其他程序进入全屏时自动最小化；另配独立的 tkinter 配置程序，所有设置存为 JSON 供主程序读取。

## 功能一览

- **16 个科目**：语文、数学、英语、物理、化学、生物、政治、历史、地理、体育、音乐、美术、心理、自习、体育模块、校本（颜色与图标文字可自定义，也可随时新增学科）
- **单双周课表**：按「学期起始日」自动推算（第 1、3、5… 周为单周，第 2、4、6… 周为双周），也支持强制单周/双周
- **配置程序（tkinter）**：
  - 编辑单周 / 双周课表（节次 × 星期，下拉选科目）
  - **课程管理**页：新增学科（对话框 + 调色盘选色）、修改颜色（选中后点按钮或双击列表项）、删除学科（自动从单双周课表与临时调课中移除该课程）、恢复内置 16 科默认颜色
  - **从 Excel 导入课表**（.xlsx / .xls / .csv）：首行为星期表头（周一~周日），其余每行一节课；导入时可选择写入单周或双周，表格中出现而配置中不存在的科目自动加入科目表
  - 临时调整任意一天课程（优先于正常课表，可填调课备注）
  - 设置学期起始日、单双周模式、每节课时间（可选）
  - **主程序显示设置**：按屏幕分辨率自动缩放（右侧模式高度占屏高 4/5，顶部模式宽度占屏宽 3/4），并可切换卡片位于屏幕右侧（竖排）或屏幕顶部（横排）
  - 导入 / 导出课表（JSON）、一键开启「开机自动启动主程序」
- **主程序（Pygame）**：
  - 启动后自动读取当前日期与课表，彩色圆形图标按节次排列，悬浮屏幕右侧（或顶部）、始终置顶
  - 检测到其他程序全屏（视频、游戏、放映等，**任务管理器全屏除外**）时自动最小化，退出全屏自动恢复
  - 配置被修改后自动热加载，跨日自动刷新；卡片右上角 `…` 打开配置程序、`×` 退出（Esc 亦可）

## 直接使用 exe（推荐，无需安装 Python）

`dist/` 目录中 `配置程序.exe` 与 `桌面课表.exe` 已打包为免安装的单文件程序：

1. 双击 `dist\配置程序.exe` → 填写单/双周课表、确认学期起始日，可勾选「开机自动启动主程序」；
2. 双击 `dist\桌面课表.exe` → 屏幕右侧出现今日课表卡片；
3. 两个 exe 与 `schedule_data.json` 必须放在**同一目录**（配置文件即存在 exe 同目录）。

> exe 版的开机自启会直接注册 exe 本身；exe 版卡片右上角 `…` 按钮也会直接打开 `配置程序.exe`。

### 重新打包 exe

```bat
pip install pyinstaller pygame openpyxl xlrd
pyinstaller --noconfirm --onefile --windowed --name "配置程序" config_app.py
pyinstaller --noconfirm --onefile --windowed --name "桌面课表" main_app.py
```

打包产物在 `dist/`；构建中间目录 `build/` 可随时删除。

## 安装依赖

```bat
pip install pygame openpyxl xlrd
```

主程序需要 pygame（建议 2.0 以上）；从 Excel 导入需要 openpyxl（.xlsx）、xlrd（.xls）；配置程序其余部分只用标准库 tkinter。
若你的 Python 较新（如 3.14）装不上官方 pygame，可用完全兼容的替代包：

```bat
pip install pygame-ce
```

本工具已在 Python 3.13 / 3.14（pygame-ce 2.5.8）下验证通过。

## 第一次使用

1. 双击 `启动配置程序.bat`（或 `python config_app.py`）；
2. 在 **单周课表 / 双周课表** 两个页签中按真实课表填写；
3. 在 **设置** 页确认「学期起始日」（应填开学第一周的周一，可点「设为本周周一」），
   需要时勾选「开机自动启动主程序」；
4. 双击 `启动课表.bat`（或 `python main_app.py`），屏幕右侧即出现今日课表卡片。

> 所有修改都会**实时自动保存**到 `schedule_data.json`，主程序无需重启即可感知变化。

## 临时调课

在配置程序的「临时调课」页：
1. 输入要调整的日期（默认今天）→ 点「载入当天正常课表」；
2. 修改课程、填写备注 → 点「保存调整」；
3. 该日主程序将优先展示调整后的课程，并显示"调课：备注"。
4. 「清除该日调整」可撤销。

## 开机自启

- 配置程序「设置」页勾选/取消「开机自动启动主程序」；
- 或命令行：`python main_app.py --autostart` / `python main_app.py --no-autostart`（exe 版为 `桌面课表.exe --autostart`）。
- 自启项写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`；
  脚本模式注册 `pythonw main_app.py`（不弹黑窗口），exe 模式直接注册 exe 本身。

## 单双周推算规则

```
周数 = (当前日期 - 学期起始日).days // 7 + 1
奇数周 → 单周课表；偶数周 → 双周课表
```

## JSON 配置结构（schedule_data.json）

```json
{
  "semester_start_date": "2026-09-21",
  "week_override": null,
  "subjects": { "语文": {"color": "#E74C3C", "short": "语"}, ... },
  "period_times": ["08:00-08:45", ...],
  "schedule": {
    "single": { "周一": ["语文", ...], ... },
    "double": { "周一": ["数学", ...], ... }
  },
  "temp_adjustments": {
    "2026-09-22": { "periods": ["物理", ...], "note": "运动会调课" }
  },
  "default_periods": 10,
  "window": {
    "width": 232,
    "mode": "right",
    "scale_to_screen": false,
    "height_ratio": 0.8,
    "width_ratio": 0.75,
    "top_height": 116,
    "top_width": 420
  }
}
```

- `week_override`：`null`=自动；`"single"`=强制单周；`"double"`=强制双周
- `default_periods`：每日默认节数（配置程序空白课表显示这么多行，示例课表为 10 节；节数不受上限限制，可用"＋ 增加一节"继续加）
- 课程列表为空字符串表示该节无课
- `temp_adjustments` 键为日期 `YYYY-MM-DD`，优先级高于正常课表
- `window.mode`：`"right"`=屏幕右侧竖排；`"top"`=屏幕顶部横排
- `window.scale_to_screen`：开启后按屏幕分辨率自动缩放；右侧模式高度占屏高 `height_ratio`（默认 4/5），顶部模式宽度占屏宽 `width_ratio`（默认 3/4）

## 从 Excel 导入课表

配置程序底部工具栏「从Excel导入…」：

1. 选择 `.xlsx` / `.xls` / `.csv` 文件，第一行须为星期表头（如 `周一 周二 … 周五`），其余每行一节课、对应列即该星期该节的课程，空单元格表示无课；
2. 选择导入到**单周课表**还是**双周课表**；
3. 表内出现的新科目会自动加入科目表（默认灰色，可稍后在「课程管理」页修改颜色）。

示例（CSV，UTF-8 编码）：

```csv
节次,周一,周二,周三,周四,周五
1,语文,数学,英语,物理,化学
2,数学,英语,语文,化学,物理
```

## 课程管理

配置程序「课程管理」页：

1. **新增学科**：点「新增学科…」，在对话框中输入学科名，点击色块打开调色盘选色，确定后即加入科目列表与所有课表下拉框；
2. **修改颜色**：在列表中选中科目 → 点「修改颜色…」（或直接双击列表项），调色盘选色；
3. **删除学科**：选中科目 → 点「删除学科…」确认后，该科目会从科目表、单周/双周课表以及所有临时调课中一并移除；
4. **恢复默认颜色**：仅将内置 16 个科目的颜色恢复为默认值，不会删除自定义学科。

## 已知限制

- 仅支持 Windows（依赖 Win32 API 实现置顶、透明与全屏检测）；
- 悬浮卡片默认定位在主显示器右侧/顶部；多显示器场景仅覆盖主屏；
- 需要 pygame ≥ 2.0（建议 2.5+）；
- 全屏检测会忽略 Windows 任务管理器（其“最大化为全屏”不会触发最小化），其余全屏程序照常触发。
